# 👕👟 TrendFlex Store 🛍️

## An E-commerce Website for T-shirts and Shoes Display

---

### **✨ Project Overview**

"TrendFlex Store" is a front-end web project developed to showcase a diverse collection of sports t-shirts and stylish shoes. This project aims to provide users with a smooth and engaging Browse experience, focusing on **responsive design** to ensure optimal display across various devices, from desktops to mobile phones.

---

### **🌟 Key Features**

* **Modern & Attractive Design:** A clean, contemporary user interface that is visually appealing.
* **Fully Responsive:** Seamlessly adapts and functions across different screen sizes (desktops, tablets, and mobile devices).
* **Organized Product Sections:** Clear distinction between T-shirts and Shoes sections for easy navigation.
* **Interactive Product Slider:** A smooth and intuitive carousel system for showcasing products within each category, complete with navigation arrows.
* **Contact Form:** Allows visitors to easily get in touch (requires integration with a back-end service like Formspree).
* **Social Media Links:** Integrated icons and links to your social media profiles.
* **Enhanced User Experience:** Interactive buttons, and smooth scrolling navigation between page sections.

---

### **🛠️ Technologies Used**

* **HTML5:** For structuring the web content.
* **CSS3:** For styling and ensuring a responsive layout.
* **JavaScript (Vanilla JS):** For interactive elements and dynamic slider functionality.
* **Boxicons:** For a rich library of icons.
